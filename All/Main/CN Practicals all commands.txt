Practical 5:
Switch Configuration -
Switch > CLI :
* en (To enable the switch)
* Conf t (To configure the terminal)
* hostname <Name>
* interface vlan1
* ip address 10.0.0.1 255.0.0.0
* No shut
* exit
* exit
* exit
Do same for Second Switch - Just change the ip address to 10.0.0.2


Practical 6:
Router Configuration -
PC > Terminal :
* en
* config t
* hostname <name>
* banner motd $<Type a message here>$
* service password-encryption
* enable password <your password>
* enable secret <your password>
* Line console 0
* password <Your password>
* login
* exit
* exit
* Enter your passwords to login
* config t
* Copy run start
